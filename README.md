# 🤖 AI Chatbot with Document Support

A ChatGPT-like AI chatbot built using Python Flask, HTML, CSS, and Groq AI API.  
The chatbot can answer general questions and interact with uploaded documents.

## 🚀 Features

- AI-powered chat using Groq LLM
- ChatGPT-style interface
- Upload documents and ask questions
- Supports PDF and DOC files
- Answers from documents when information is available
- Uses AI when the answer is not found in the document
- Web-based interface
- Deployed online using Render

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Groq AI API
- PyPDF2
- python-docx
- Scikit-learn
